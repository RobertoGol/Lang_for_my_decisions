# KINII Language — расширение VS Code

Язык KINII (VOID-Core v3): файлы `.vc` и `.ctos`.

## Что умеет

- Подсветка всех ключевых слов, типов и встроенных функций по лексеру `kinic`
  (что компилятор знает — то и цветит).
- Цветизация скобок `{ } [ ] ( )` — встроенная настройка языка.
- Автозакрытие `{`, `[`, `(`, `"`.
- Правильные комментарии `//`, заголовки слоёв `//---- [SYS] ----/` выделяются
  отдельно как баннеры.
- Блок `?sql ... ?>` (уровень .web) выделяется как встраиваемый SQL.
- Сниппеты: `entry`, `fn`, `fnv`, `let`, `const`, `struct`, `enum`, `if`,
  `while`, `for`, `decide`, `comp`, `imp`, `layer`, `pubfn`.
- **Живая диагностика `kinic` через LSP**: ошибки парсера и семантики прямо в
  редакторе (красные подчёркивания + список ошибок), как в VS Code для любой
  обычной языковой пары. Сервер `kinic lsp` стартует как дочерний процесс,
  пересобирает проверку проекта при каждом изменении текста. Ссылки вида
  «объявлен в другом файле» показываются в деталях диагностики.

## Установка

1. Скопируйте папку `kinii` в каталог расширений VS Code:
   - Windows: `%USERPROFILE%\.vscode\extensions`
   - Linux/macOS: `~/.vscode/extensions`
2. Перезапустите VS Code.
3. Откройте рабочую папку проекта (где лежит `project.kinii`) и любой
   `.vc`/`.ctos` файл — справа внизу должен появиться KINII, а ошибки уже
   будут подсвечены.

## Настройки

- `kinii.serverPath` — путь к `kinic` (абсолютный или от корня рабочей папки).
  По умолчанию `compiler/build/kinic.exe`.
- Команда палитры **KINII: перезапустить сервер kinic** — если что-то пошло
  не так с сервером.

## Как это работает

- `extension.js` запускает `kinic lsp` (JSON-RPC 2.0 поверх stdio, фреймы
  Content-Length) с рабочей папкой проекта.
- didOpen/didChange шлют полный текст файла (серверу не нужно читать диск,
  текст из редактора всегда приоритетнее дискового).
- Сервер после каждого изменения публикует `publishDiagnostics` — только
  диагностики этого файла; ошибки из других файлов проекта появятся при
  их открытии.
